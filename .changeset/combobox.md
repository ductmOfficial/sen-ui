Add `ComboBox` and `ComboBoxItem`, built on React Aria Components: a labelled text input that filters a list of options as the user types. The list opens on typing, ArrowDown or the button; arrow keys move through matches, Enter selects and Escape closes. Supports a `description`, an `error` that marks the field invalid, `emptyText` when nothing matches, `defaultItems` for local filtering, and `items` with `inputValue` / `onInputChange` for options loaded from a server.
