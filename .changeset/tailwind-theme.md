Add `@ductmofficial/sen-ui/tailwind.css`, a Tailwind CSS v4 theme that maps the design tokens to utilities such as `bg-sen-bg`, `text-sen-fg`, `border-sen-border`, `rounded-sen-md` and `font-sen`. Import it after `tailwindcss` and the tokens. The utilities reference the tokens directly, so they follow the light and dark themes.
