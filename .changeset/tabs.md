Add `Tabs`, `TabList`, `Tab` and `TabPanel`, built on React Aria Components. Arrow keys move between tabs (Home and End jump to the ends, disabled tabs are skipped), only the selected tab is in the tab order, and each tab controls its panel. Selection follows focus unless `keyboardActivation="manual"`; use `selectedKey` / `defaultSelectedKey` with `onSelectionChange`, and `orientation="vertical"` for a side list.
